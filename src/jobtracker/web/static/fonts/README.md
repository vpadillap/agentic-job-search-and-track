# Fonts

Self-hosted so the panel works offline and makes no third-party requests.

| File | Family | Weights | Subset |
|---|---|---|---|
| `inter-latin.woff2` | Inter | variable (400–700) | latin |
| `space-grotesk-latin.woff2` | Space Grotesk | variable (500–700) | latin |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | variable (500–600) | latin |

The files are Google Fonts' latin subsets, taken unchanged from the bundle in
`design/panel-ux.html`. They cover English and Spanish text. All three families
are licensed under the SIL Open Font License 1.1; see `OFL.txt`.
