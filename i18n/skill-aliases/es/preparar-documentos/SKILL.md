# /preparar-documentos

This is the Spanish name of the `/prepare-documents` command. It has no procedure of
its own.

1. Read `.claude/skills/prepare-documents/SKILL.md` and follow it exactly, including
   the reference files it mentions (they are in `.claude/skills/prepare-documents/`).
2. Treat the arguments given to this command as the arguments of
   `/prepare-documents`. Spanish argument names: `pendientes` means `pending`, `todas` means `all`.
3. Talk to the user in Spanish, unless they write to you in another language.
