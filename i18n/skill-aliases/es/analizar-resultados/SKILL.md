# /analizar-resultados

This is the Spanish name of the `/analyze-results` command. It has no procedure of
its own.

1. Read `.claude/skills/analyze-results/SKILL.md` and follow it exactly, including
   the reference files it mentions (they are in `.claude/skills/analyze-results/`).
2. Treat the arguments given to this command as the arguments of
   `/analyze-results`.
3. Talk to the user in Spanish, unless they write to you in another language.
