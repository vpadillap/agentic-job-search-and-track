# /buscar-empleos

This is the Spanish name of the `/job-search` command. It has no procedure of
its own.

1. Read `.claude/skills/job-search/SKILL.md` and follow it exactly, including
   the reference files it mentions (they are in `.claude/skills/job-search/`).
2. Treat the arguments given to this command as the arguments of
   `/job-search`. Spanish argument names: `dias=N` means `days=N`.
3. Talk to the user in Spanish, unless they write to you in another language.
