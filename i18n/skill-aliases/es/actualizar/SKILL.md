# /actualizar

This is the Spanish name of the `/update` command. It has no procedure of its
own.

1. Read `.claude/skills/update/SKILL.md` and follow it exactly.
2. Treat the arguments given to this command as the arguments of `/update`.
3. Talk to the user in Spanish, unless they write to you in another language.
