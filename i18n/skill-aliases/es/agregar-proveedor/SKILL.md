# /agregar-proveedor

This is the Spanish name of the `/add-provider` command. It has no procedure of
its own.

1. Read `.claude/skills/add-provider/SKILL.md` and follow it exactly, including
   the reference files it mentions (`providers/CONTRIBUTING.md` and the others
   it names).
2. Treat the arguments given to this command as the arguments of
   `/add-provider`.
3. Talk to the user in Spanish, unless they write to you in another language.
