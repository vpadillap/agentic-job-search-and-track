# /configurar

This is the Spanish name of the `/setup` command. It has no procedure of
its own.

1. Read `.claude/skills/setup/SKILL.md` and follow it exactly, including
   the reference files it mentions (they are in `.claude/skills/setup/`).
2. Treat the arguments given to this command as the arguments of
   `/setup`.
3. Talk to the user in Spanish, unless they write to you in another language.
